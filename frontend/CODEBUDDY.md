## 初始化步骤（未做则先做）

1. `npm create vite@latest . -- --template vue`（在 `frontend/` 内）
2. 安装依赖：`vue-router`、`pinia`、`axios`
3. 配置 Vite 代理（**禁止直连 `http://localhost:8080`**）：

```js
server: {
  proxy: { '/api': 'http://localhost:8080' }
}
```

4. npm 源指向 `https://registry.npmmirror.com/`（下载卡住先查这个）

## 页面清单（实验一）

| 页面 | 路由建议 | 状态要求 |
| --- | --- | --- |
| 登录页 | `/login` | 用户名/密码表单；漏填提交时**指出缺失字段、不跳转**；提交中显示等待状态并**禁用按钮防重复提交**；失败展示 `message`；成功按角色跳转 |
| 欢迎页 | `/welcome` | 显示用户名（用 `displayName`）；提供退出按钮 |

## 请求与状态纪律

1. **前端不产生业务数据**：不保存账号列表、不校验凭据正确性，一切以后端返回为准。
2. 所有请求走 `/api/**`，axios 基础路径设为 `/api`；**不要手动携带 Cookie**（代理同源自动携带）。
3. 业务结果按响应体的 `code` 分支处理（`0`=成功，`1001`/`1002`/`4001`…见契约错误码表），**禁止用 HTTP 状态码判断业务结果**（业务失败也是 HTTP 200）。
4. 登录态判断：调 `GET /api/identity/me`，`code=0` 放行，`1002` 跳登录页。路由守卫统一做。
5. 任何字段、路径以契约为准；发现契约缺东西 → 先提出来改契约，**不许代码里私加字段**。

## 验收自查（提交前逐条过）

- [ ] 未登录打开系统 → 显示登录表单
- [ ] 漏填用户名或密码提交 → 指出缺失字段，不跳转
- [ ] 提交中 → 显示等待状态，按钮禁用（防重复提交）
- [ ] 密码错误（后端 `1001`）→ 显示失败提示，不进入欢迎页
- [ ] 登录成功 → 进入欢迎页，显示用户名
- [ ] 退出 → 返回登录页；浏览器后退/直接输地址进受保护页 → 被守卫拦回登录页
- [ ] 换账号登录 → 只显示新账号的数据
