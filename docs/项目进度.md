- 高校学生成绩管理系统，前后端分离
- 后端：Spring Boot 3 + MyBatis-Plus + MySQL 9 + Flyway + Session 认证（`backend/`）
- 前端：Vue 3 + Vite + Pinia + Vue Router + Axios（`frontend/`）
- UI 规范：`D:\javaweb\原型html\proto_kit.py` 设计系统（indigo-600 + slate 卡片风），静态原型图在 `原型图片/`（80 个状态目录）
